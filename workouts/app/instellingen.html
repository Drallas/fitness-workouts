Garmin Connect Garmin has an API, but it's only for approved partners. For a personal app, uploading the FIT file by hand keeps working. That already goes well. Manual via FIT file

GitHub

Finished trainings go to the repo from here.

How to get a token: open the page below, pick Only select repositories and choose fitness-workouts. Under Repository permissions set Contents to Read and write. Choose an expiry date, generate the token and copy it. It starts with github_pat_. Paste it here.

Create a new token on GitHub ↗

Export and import

Export saves all trainings on this device to one JSON file. Import adds trainings from such a file. Trainings that already exist here are left alone.

Start weights

The weights the app uses as start weight for a new workout, overwritten by what you entered yourself. Clearing resets them to the Strava values. Your history itself stays on the History page.

    Trash

    Deleted trainings wait here until you wipe them for good. You can restore them in the meantime. They no longer count in the lists or the history.

      Danger zone

      Moves all trainings on this device to the trash. Trainings on GitHub stay.
